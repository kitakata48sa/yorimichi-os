# よりみちOS

現在地、空き時間、次の予定、個人の嗜好から「今から行く意味がある場所」を探すための個人用都市探索アプリです。

## 現在の使い方

1. 現在地、到着期限、気分を入力します。
2. 「調査依頼を作る」を押します。
3. 生成した依頼文をM365 Copilotへ渡します。
4. Copilotが返したJSONをアプリへ貼り付けます。
5. 営業成立性、嗜好、今日行く価値、情報信頼度で候補を再順位付けします。
6. 訪問、保存、見送りをローカル履歴へ記録します。

## プライバシー

位置、好み、訪問履歴はブラウザのlocalStorageに保存されます。GitHubリポジトリには個人データやAPIキーを保存しません。

## 公開

Netlifyにこのリポジトリを接続すると、`main`ブランチ更新時に自動再公開できます。ビルドコマンドは不要で、公開ディレクトリは `.` です。
