# よりみちOS v0.2.0

外部記憶を読み込み、推薦への反応を場所台帳へ戻す循環型都市探索プロトタイプです。

## v0.2の機能
- GitHub上の `places.json`、`watch-sources.json`、`preference-profile.json` を読み込み
- 行ってみたい、行った、また行きたい、今回は見送り、今後は勧めない
- 訪問後30秒レビュー
- ローカル場所台帳と初期データの重複統合
- 調査依頼へ優先候補と除外候補を挿入
- 更新済み場所台帳と更新パケットのJSON書き出し

## データ同期
v0.2.0では日常操作をlocalStorageへ即時保存します。定期的に「更新パケットを書き出す」でJSONを保存し、M365 Copilotへ渡して `places.json` に統合します。GitHubへの自動書込は次段階です。
